# Developer Transparency Tags

> ℹ️ 🚧 **Draft in progress.** Scaffolded from the approved architecture; full write-up to follow.

1Edge automatically tags tokens with transparency flags so traders can see meaningful creator behaviour without manual on-chain forensics.

## Planned coverage

* **Atomic Dev Buys** — highlighting when a token creator launches with a pre-configured initial purchase built into the **same deployment transaction**. Explains what this means, why it's surfaced, and how to interpret it.
* Other automated flags as they're added.

> ⚠️ An atomic dev-buy isn't inherently bad — many legitimate launches use one. The point of the tag is **transparency**: traders see it clearly and decide for themselves.
